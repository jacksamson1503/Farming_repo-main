# Smart Farming - Control Every Field with Ease

A bilingual (Tamil / English) modern smart farming and agriculture assistant web application.

## Live Demo
Check out the live web app on GitHub Pages:
https://jacksamson1503.github.io/Farming_repo-main/

## Features
- **Bilingual Support**: Instant toggle between English and தமிழ்.
- **District-wise Crop & Soil Advisory**: Tailored recommendations for Tamil Nadu & Karnataka regions.
- **Live Weather Integration**: Real-time forecast via Open-Meteo API.
- **Mandi Market Prices**: Reference price trends for major agricultural commodities.
- **PWA & Offline Ready**: Service Worker caching with `manifest.json`.
